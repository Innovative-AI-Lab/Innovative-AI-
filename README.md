## 💀 What is Innovative AI?

**Innovative AI** is a premium, state-of-the-art **AI-powered full-stack development platform** designed for modern developers and teams. 

It seamlessly combines:
- 💬 **Real-time collaboration & Team Chat**
- 🤖 **Advanced AI Assistant (Powered by Gemini)**
- 💻 **Integrated Code Editor**
- 📂 **Smart File Manager**
- 🖥 **Live Terminal Execution**

👉 Everything developers need to brainstorm, write, execute, and debug code—in ONE unified, beautiful workspace.

## 🧠 Tech Stack

### 🛠 Backend
- **Node.js & Express.js**: High-performance RESTful API.
- **MongoDB**: Scalable NoSQL database with Mongoose ORM.
- **Socket.io**: Real-time bidirectional event-based communication.
- **JWT & bcrypt**: Secure authentication and password hashing.
- **Google Gemini API**: Cutting-edge AI model integration.

### 🎨 Frontend

## ⚙️ Local Installation

Get the platform running on your local machine in just a few steps:

```bash
git clone https://github.com/Innovative-AI-Lab/Innovative-AI-
cd Innovative-AI-
```

### 📦 Backend Setup
```bash
cd Backend
npm install
npm run dev
```

### 🎨 Frontend Setup
```bash
cd Frontend
npm install
npm run dev
```

### 🔐 Environment Variables
You must set up `.env` files in both the `Backend` and `Frontend` directories.

**Backend `.env`**
```env
PORT=4001
MONGODB_URI=mongodb://localhost:27017/ChatApp
JWT_SECRET=your_super_secret_jwt_key
GEMINI_API_KEY=your_gemini_api_key
FRONTEND_URL=http://localhost:5173
```

**Frontend `.env`**
```env
VITE_API_URL=http://localhost:4001
```

> ⚠️ **Security Warning**: Never push your `.env` files to GitHub.

## 🚀 Deployment

### Frontend (Vercel / Netlify)
1. Navigate to the `Frontend` directory.
2. Run `npm run build`.
3. Deploy the `dist` folder to your preferred hosting provider.

### Backend (Render / Railway / AWS)
1. Navigate to the `Backend` directory.
2. Ensure environment variables are set in your hosting provider's dashboard.
3. Deploy using standard Node.js runtime configurations.
